# Прогнозирование стоимости акций на основе макроэкономических факторов

## О проекте
Дипломная работа, посвящённая прогнозированию цен акций с использованием статистических и машинных методов.
Задача: сравнить классические эконометрические модели (ARIMA) с современными ML-подходами (Ridge, Random Forest) и выявить наиболее точный инструмент для финансового прогнозирования.

## Данные
Использован датасет с историческими котировками акций и макроэкономическими индикаторами (курс доллара, цена на нефть, инфляция, ключевая ставка ЦБ).
Данные предварительно очищены и приведены к стационарному виду (логарифмические приросты).

## Использованные методы и технологии
- **Язык:** Python
- **Библиотеки:** pandas, numpy, statsmodels, scikit-learn, matplotlib, seaborn
- **Модели:** ARIMA (ручной подбор параметров), Ridge-регрессия (с кросс-валидацией), Random Forest
- **Анализ:** проверка стационарности (ADF-тест), ACF/PACF анализ, диагностика остатков (Ljung-Box, Jarque-Bera), VIF-анализ мультиколлинеарности

## Результаты
- Построены и провалидированы три типа моделей
- Проведён детальный анализ остатков и значимости факторов, влияющих на цену акций
- Сравнение моделей показало, что ARIMA даёт более устойчивый прогноз на тестовой выборке
